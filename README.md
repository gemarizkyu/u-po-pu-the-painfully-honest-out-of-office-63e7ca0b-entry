A deterministic program that writes one brutally honest but still polite out-of-office auto-reply — a single sentence of at most 200 characters — for make.fun's "The Painfully Honest Out-of-Office" bounty. No network, no randomness, no model calls: the reply is fixed in the source and written to `/output/entry.txt`.

The reply it writes:

> I'm out of office until Monday, and truthfully I've been avoiding my inbox — 400 unread emails deep — but your message matters, and I'll answer it properly the moment I'm back.

## Run it

```sh
node main.ts
```
